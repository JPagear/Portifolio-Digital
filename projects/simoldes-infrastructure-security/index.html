01ContextoContext

Estágio curricular na Simoldes Tools (Oliveira de Azeméis), com trabalho direto em ambiente de produção industrial do Grupo Simoldes. O foco: segurança defensiva, observabilidade e administração de sistemas em infraestrutura real.

Curricular internship at Simoldes Tools (Oliveira de Azeméis), working directly in the industrial production environment of the Simoldes Group. The focus: defensive security, observability and systems administration on real infrastructure.

02DesafioChallenge

Consolidar a monitorização de segurança e de rede de várias unidades industriais, endurecer o SIEM e integrar as diferentes fontes de telemetria (endpoint, firewall e cloud) num ambiente que não pode parar.

Consolidate security and network monitoring across several industrial units, harden the SIEM and integrate the different telemetry sources (endpoint, firewall and cloud) in an environment that cannot stop.

  • Fontes externas integradas: VirusTotal, Office 365, FortiGate e Docker
  • Dashboards OpenSearch para monitorização de vulnerabilidades
  • Zabbix · 39 mapas de rede cobrindo 8 unidades industriais
  • Infraestrutura virtualizada em Hyper-V com Active Directory e GPOs
  • Wazuh SIEM in production with 19 active agents
  • External sources integrated: VirusTotal, Office 365, FortiGate and Docker
  • OpenSearch dashboards for vulnerability monitoring

  • Virtualized infrastructure on Hyper-V with Active Directory and GPOs

04ImplementaçãoImplementation

Implementação, configuração e hardening do SIEM Wazuh em produção, com integração das fontes de dados: VirusTotal, Office 365, ingestão de eventos FortiGate (4,7M+ alertas) e Docker. Desenvolvimento de dashboards OpenSearch para monitorização de vulnerabilidades e construção dos 39 mapas de rede Zabbix para as 8 unidades industriais do grupo.

Em paralelo, gestão de infraestrutura virtualizada em Hyper-V e administração de servidores Windows e Linux, com um laboratório completo (Active Directory, DNS/DHCP, File Server e GPOs) para testar configurações antes de tocar em produção.

Deployment, configuration and hardening of the production Wazuh SIEM, integrating the data sources: VirusTotal, Office 365, FortiGate event ingestion (4.7M+ alerts) and Docker. Development of OpenSearch dashboards for vulnerability monitoring and construction of the 39 Zabbix network maps for the group's 8 industrial units.

In parallel, management of virtualized infrastructure on Hyper-V and administration of Windows and Linux servers, with a complete lab (Active Directory, DNS/DHCP, File Server and GPOs) to test configurations before touching production.

05Monitorização & SegurançaMonitoring & Security

Alinhamento das configurações e controlos com o framework NIS2, aplicado em ambiente real. Observabilidade de rede centralizada em Zabbix; deteção no endpoint e correlação de eventos no Wazuh, com dashboards OpenSearch para vulnerabilidades.

Configurations and controls aligned with the NIS2 framework, applied in a real environment. Centralized network observability in Zabbix; endpoint detection and event correlation in Wazuh, with OpenSearch dashboards for vulnerabilities.

06ResultadoResult

Monitorização de segurança e de rede consolidada para 8 unidades industriais, SIEM endurecido com fontes externas integradas e dashboards de vulnerabilidades, e um laboratório reproduzível para validar mudanças. 680 horas de trabalho em infraestrutura de produção.

Consolidated security and network monitoring for 8 industrial units, a hardened SIEM with integrated external sources and vulnerability dashboards, and a reproducible lab to validate changes. 680 hours of work on production infrastructure.
